# Sovara plugins

Bring your company’s tacit knowledge to AI agents. Retrieve relevant lessons, inspect recorded agent runs, and propose improvements for review.

- **[Sovara](sovara)** connects to your organization through OAuth.
- **[Sovara Local](sovara-local)** connects to Sovara on your computer using your signed-in desktop account. The host starts the connection automatically.

Each package includes the Sovara skill and MCP configuration. These packages contain no Sovara server or desktop application source.
